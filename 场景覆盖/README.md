# 场景覆盖

读「场景覆盖」六块（等级、玩法、地图、遭遇、偏好、流派三维），按地图档位和 PVE/PVP 比例算流派效用，写回「覆盖率结果」。

## 运行

```bash
cd 数值工具
python 启动_场景覆盖.py -w ../数值框架/战斗数值框架.xlsx
```

## 包

```
场景覆盖/
  pipeline.py          入口
  config.py            路径、表名、异常
  load/                场景表、克制矩阵
  calc/                地图效用、矩阵运算；命中桥接供其他启动器
  write/               覆盖率结果（平衡总览 + 地图流派）
  旧口径/              上一版四层读表和五维排名，当前入口不调用
```

平衡总览在结果表最左：平衡指数 1 为全体平均，偏离 ±3% 为合理。
